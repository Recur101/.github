# Recur101

🎓 **Recur101** is a GitHub organization created for managing and collaborating on **university lab projects**, assignments, and academic work.

This organization provides a structured environment to practice **Git**, **team collaboration**, and **project organization** as part of university coursework.

---

## 📌 Purpose

- Manage university lab projects and assignments  
- Collaborate with teammates using GitHub  
- Practice version control, branching, and commits  
- Maintain clean and organized academic repositories  
- Track progress throughout the semester  

---

## 🧪 Types of Projects

Repositories under **Recur101** may include:

- Programming lab assignments  
- Course projects (OOP, DSA, OS, etc.)  
- Mini projects and experiments  
- GUI-based applications  
- Documentation and reports
